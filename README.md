# Food-Delivery-Website-with-add-to-card-functionality


A responsive Food Delivery Website built using HTML, CSS, JavaScript, and JSON. Users can browse food items, add products to the cart, update quantities, remove items, and view the total price dynamically.

## Features

- Dynamic product cards loaded from JSON
- Add to Cart functionality
- Increase and decrease quantity
- Remove products from cart
- Automatic total price calculation
- Cart item counter
- Responsive design
- Customer review slider using Swiper.js
- Mobile navigation menu

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- JSON
- Font Awesome
